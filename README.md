# Ticket Escalation Workflow Simulation

This Python script simulates a support ticket escalation system. Tickets with varying complexities are processed through multiple support levels. If a lower level cannot resolve a ticket, it is automatically escalated to the next higher level, demonstrating a core principle of effective escalation management.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
